# CaO2 硬件工程说明 (Hardware README)

## 📌 项目概述
`CaO2` (Calcium Dioxide) 是一台采用双核异构架构的高性能图形计算器。硬件工程基于 **KiCad 10.0** 设计，将“人机交互”与“符号计算 (CAS)”在物理层面彻底隔离。

*   **控制核 (Control Core)**：GD32F303VGT6，负责 UI 渲染、键盘扫描、传感器采集及外设控制。
*   **计算核 (Compute Core)**：MIMXRT1011，专职处理 AST（抽象语法树）解析与复杂数学运算。

---

## 🧩 核心模块与器件选型

### 1. 双核通信总线
*   **高速并口 (EXMC <-> FlexIO)**：20 根线（16位数据 + 3根控制 + 1根地址），用于极速吞吐 AST 数据。
*   **辅助控制 (SPI0)**：4 根线，用于短指令和心跳包。
*   **中断线**：双向独立硬中断（INTGD / INTMX）。

### 2. 存储与计算核心 (RT1011)
*   **程序 Flash**：W25Q128JVS (16MB QSPI)。
*   **运行内存**：APS6404L (8MB QSPI PSRAM)。
*   *注意：因无 DQS 引脚，最高运行速率受限。*

### 3. 电源与电池管理
*   **主控芯片**：TPS631000 (Buck-Boost 升降压至 3.3V)。
*   **电池保护**：DW01KA + 8205A (硬件级过放/过流保护)。
*   **电压采样**：100k + 100k 分压，SS8050 低边开关控制（防漏电）。

### 4. 外设接口
*   **屏幕**：4寸 TFT (ILI7796)，硬件 SPI 驱动，支持 PWM 背光调光。
*   **键盘**：7x7 矩阵键盘 + 带按压旋编。
*   **传感器**：BME280 (环境)、MPU6050 (六轴)、IST8310 (磁力计)、驻极体麦克风。
*   **外部通信**：3.5mm 耳机孔（单线半双工 UART 通信 + 插入检测）。

## 🔌 关键引脚映射表 (Pinout)

### 双核高速并口 (EXMC)
| 信号 | GD32 引脚 | RT1011 引脚 | 说明 |
| :--- | :--- | :--- | :--- |
| EXMC_D0~D15 | PD14/15, PD0/1, PE7~15, PD8~10 | 分散于 GPIO_AD 与 GPIO_SD | 16 位并行数据线 |
| EXMC_NE / NWE / NOE | PD7 / PD5 / PD4 | GPIO_03 / 04 / 05 | 读写控制与片选 |
| EXMC_A16 | PD11 | GPIO_06 | 地址线（命令/数据切换） |

### 控制核外设分配
*   **TFT 屏幕**：SPI1 (`PB12~PB15`)，控制线 `PC8~PC12`。
*   **矩阵键盘**：`PE7~PE15` (行)，`PD8~PD12` (列)。
*   **I2C 传感器**：I2C0 (`PB6`, `PB7`)，地址分别为 0x76, 0x68, 0x0E。
*   **耳机通信**：`PA2` (COM_TX)，`PA3` (COM_RX)，插入检测 `PE0/PE1`。

## ⚠️ 硬件设计规范与 PCB Layout 避坑指南

在进行 PCB 布局与布线时，必须严格遵守以下规范：

### 1. 高速与并行总线 (EXMC)
*   **等长与平行**：16 根数据线必须同层走线，平行且等长，避免频繁换层打孔。
*   **参考地平面**：总线正下方必须有完整的地平面，**绝对不允许跨越电源分割区**，以保证高速信号的阻抗连续和回流路径完整。

### 2. 电源与 DCDC 环路
*   **去耦电容**：所有芯片的 0.1uF 去耦电容必须**紧贴 VDD 引脚**（先过孔后引脚）。
*   **开关环路**：RT1011 内部 DCDC 和 TPS631000 的电感与滤波电容必须紧贴芯片引脚。LX 节点走线要极短、极粗，**严禁大面积铺铜**（作为天线会向外辐射干扰）。

### 3. 晶振与时钟隔离
*   8MHz (GD32) 和 24MHz (RT1011) 晶振必须紧靠主控。晶振下方**挖空禁铺铜**，周围加 GND 过孔包地。走线远离任何高速信号线。

### 4. 模拟信号与静电保护
*   **麦克风与电池采样**：模拟走线（MIC, VBAT）尽量短，两侧用地线包围，远离数字总线。
*   **耳机孔防静电**：串接的 100Ω 电阻和 1N5819 钳位二极管必须**紧贴耳机座摆放**，确保静电在进入板内深处前被泄放。

### 5. 接口与热插拔
*   **TF 卡槽**：电源去耦电容紧贴卡槽，`DAT1` / `DAT2` 需加上拉电阻。
*   **电池座**：TPS631000 的输入大电容需尽可能靠近电池接口，应对插拔瞬间的浪涌电流。

## 📂 文件结构说明
*   `CaO2.kicad_pro` / `.kicad_sch` - 主工程与顶层图纸。
*   `Power.kicad_sch` - 电源树、电池保护与分压检测。
*   `GD32.kicad_sch` - 控制核最小系统与外设接口。
*   `RT1011.kicad_sch` - 计算核最小系统与 FlexSPI 存储器。
*   `Keypad.kicad_sch` - 矩阵键盘、屏幕、传感器等外设细节。
